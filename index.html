Pairing rules — applied in priority order
  • Priority 1No repeat pairings — reads all past Round sheets and blocks any pair that has already met.
  • Priority 2Industry match — pairs fellows where one person's industry interests overlap with the other's primary industry.
  • Priority 3Different cohorts — avoids pairing fellows from the same cohort where possible.
File format
1Your file needs a sheet named Fellows with columns: Name, Email, Opt-in, Cohort, Primary Industry, Industry interests.
2Past rounds live on sheets named Round 1, Round 2, etc. in your existing format.
3After generating, export the file — a new Round N sheet is added automatically in the same format.
